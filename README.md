# Memory Game

A card-matching memory game built with **HTML, CSS and vanilla JavaScript** (no libraries).

## Features
- 16 cards (8 pairs), shuffled every game
- Move counter and timer
- Matching cards stay open, wrong pairs flip back
- Win message when all pairs are found
- Best score (fewest moves) is saved in the browser
- Dark theme and mobile friendly

## How to run
No installation needed. Download the files and open `index.html` in your browser.

## What I practiced
- Game state (`firstCard`, `lockBoard`, `moves`)
- Shuffling an array with the Fisher-Yates algorithm
- `setTimeout` and `setInterval`
- `localStorage` for saving the best score
- Creating elements and handling events
